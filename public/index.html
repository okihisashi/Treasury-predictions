β の算出方式:Method B(確率重み付き・極端値カット)

Polymarket のバイナリー契約(↑$X 到達確率)を価格分布とみなし、レンジごとの代表値で期待価格 E[price] を計算。極端な上昇シナリオは保守的にキャップ(>$100 ゾーンを $130 ではなく $110 で代表)。

E[price] = Σ ( レンジ確率 × レンジ代表値 [上限キャップ付き] )
β(年率) = ( E[price] / 現在価格 − 1 ) × ( 12 / 残月数 )

HYPE 計算例(現価格 $40・残 7ヶ月):

E = 0.58×$110 + 0.25×$90 + 0.02×$50 + 0.06×$18 + 0.09×$12 = $89.5
期間収益 = $89.5 / $40 − 1 = +124%
β(年率・線形換算)= +124% × (12/7) ≈ +212%

※ α = ネイティブインカム利回り(月額キャッシュフロー)。α+β = 1年あたり期待トータルリターン。複利でなく線形換算(保守的)。
